How do I…

…take over a chat from the AI?
Open the chat and flip the switch at the top right to Human. The AI stops replying to that buyer and the reply box unlocks. Flip back to AI to hand it back; the AI answers the buyer's next message. Human mode lapses by itself 30 minutes after you stop viewing the chat.
…know a human is needed?
When the AI escalates, a popup appears and the Needs human tab (top bar) lists the chat with a countdown. WhatsApp only allows free-text replies for 24 hours after the buyer's last message; the same countdown sits beside the phone number in the chat. After it closes, only approved templates can be sent.
…name a number?
In the Inbox click the ⋮ next to the number → type a reference name → Save. Search then matches the name or the number.
…delete a chat?
Inbox → ⋮ → Delete chat → confirm. The conversation is removed from Supabase and Redis and its name is cleared. A transcript copy and who deleted it are kept on the Logs page. If the buyer writes again later, a fresh chat starts.
…load old conversations into the inbox?
Ops console → Import chat history. It copies every conversation held in Redis into Supabase and skips chats already there. Safe to run again. Message times are estimated because Redis keeps only the last-activity time.

Settings (environment variables on Render)

  • INBOX_ADMIN_TOKEN – the inbox login password and API bearer token.
  • SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY – server-side database access (never put the service key in the browser).
  • SUPABASE_ANON_KEY – optional; enables instant Realtime push. The inbox also polls every 3 seconds without it.
  • UPSTASH_REDIS_REST_URL / …_TOKEN – conversation memory.
  • FOLLOWUPS_CRON_TOKEN – lets the scheduled follow-up job call the server.
